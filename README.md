# IPTV WORLD

مشغل قوائم M3U بواجهة عربية متجاوبة، يعمل على متصفحات الهاتف والحاسوب وأجهزة Android TV التي تدعم متصفحاً حديثاً.

## المزايا
- مشغل فيديو مدمج مع دعم HLS عبر hls.js عندما يسمح المتصفح والمصدر بذلك.
- تحميل قائمة M3U من رابط أو ملف محلي.
- البحث في أسماء القنوات والدول والمجموعات.
- أقسام تصنيفية للمغرب وTNT والرياضة والأفلام وفق بيانات القنوات الموجودة داخل القائمة.
- مفضلة محفوظة محلياً على الجهاز.
- تذكر آخر رابط قائمة تم استخدامه.
- واجهة متجاوبة مع الهاتف والتلفاز، ووضع PWA أساسي عبر manifest وservice worker.
- تبديل اتجاه الواجهة واللغة بين العربية والفرنسية (ترجمة عناصر الواجهة الأساسية).

## التشغيل والنشر
1. افتح `index.html` محلياً أو انشر المستودع عبر GitHub Pages.
2. عند استخدام GitHub Pages: افتح Settings ثم Pages، واختر Deploy from a branch ثم الفرع `main` والمجلد `/(root)`.
3. أضف قائمة M3U تملك حق استخدامها، إما برابط HTTP/HTTPS أو بتحميل ملف من الجهاز.

## تنبيهات
- تصنيفات المغرب وTNT والرياضة والأفلام تعتمد على أسماء القنوات وبيانات `group-title` و`tvg-country` داخل قائمة M3U؛ لذلك قد لا تظهر كل قناة في القسم المتوقع إذا كانت بيانات القائمة ناقصة.
- لا يحتوي المشروع على روابط قنوات مدفوعة أو آليات لتجاوز الاشتراكات.
- لا يمكن ضمان تشغيل كل رابط؛ فقد يكون المصدر متوقفاً أو يمنع CORS أو يتطلب ترميزاً/تطبيقاً غير مدعوم في المتصفح.
- المفضلة ورابط القائمة يحفظان في التخزين المحلي للمتصفح على الجهاز نفسه.
- لا يتضمن التطبيق جدول مباريات أو مكتبة أفلام مستقلة؛ يعرض فقط القنوات الموجودة في قائمة M3U التي يضيفها المستخدم.
- لم يتم اختبار كل روابط البث على أجهزة فعلية. نجاح تشغيل القنوات يعتمد على المصدر والشبكة والمتصفح.
