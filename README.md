# مِدار — مشغّل IPTV

واجهة ويب عربية متجاوبة ومهيأة كتطبيق PWA لتشغيل قوائم M3U التي يملك المستخدم حق استخدامها. التطبيق لا يتضمن قنوات أو اشتراكات، وتبقى القوائم والمفضلة محفوظة محلياً في المتصفح.

## التشغيل

يمكن نشر المشروع مباشرة كصفحة ثابتة عبر GitHub Pages أو أي استضافة ملفات ثابتة تدعم HTTPS. افتح رابط الموقع في متصفح حديث، ثم أضف ملف M3U أو رابط قائمة يسمح خادمها بالوصول من المتصفح.

للتطوير المحلي، شغّل خادماً محلياً من مجلد المشروع، مثلاً:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## المزايا

- تصميم عربي RTL متجاوب مع الهاتف والكمبيوتر.
- استيراد ملفات وروابط M3U، بحث وتصنيفات ومفضلة وسجل مشاهدة.
- تثبيت كتطبيق PWA وتخزين ملفات الواجهة الأساسية للعمل دون اتصال.
- تشغيل HLS عبر hls.js في المتصفحات المدعومة، أو عبر مشغّل HTML5 الأصلي عند توفره.
- حفظ البيانات في المتصفح فقط، مع خيار حذف القائمة من إدارة القوائم.

## ملاحظات التوافق

لا يوجد مشغّل يضمن عمل كل سيرفر أو بروتوكول أو اتصال إنترنت. تشغيل القنوات يعتمد على دعم المتصفح للترميز والبروتوكول، وتوفر رابط بث مباشر وصلاحياته، وسياسات CORS لدى خادم القائمة والبث. استيراد رابط قائمة من نطاق آخر قد يتعذر إذا لم يسمح ذلك الخادم بطلبات المتصفح؛ يمكن حينها تنزيل ملف M3U واستيراده محلياً. بث HTTPS قد لا يعمل من موقع HTTP بسبب قيود المحتوى المختلط. يتطلب تثبيت PWA عادةً موقعاً آمناً عبر HTTPS (أو localhost).

لا تضع كلمات مرور أو روابط اشتراك خاصة في صفحات عامة. استخدم المحتوى المصرّح به فقط. hls.js وخطوط Google Fonts تُحمّل من CDN عند توفر الإنترنت.
