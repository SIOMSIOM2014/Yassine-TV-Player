# IPTV WORLD

نسخة محسّنة أولية مبنية على كود HTML الذي أرسلته.

## الملفات
- `index.html`: التطبيق.
- `manifest.webmanifest`: تعريف PWA.
- `sw.js`: تخزين أساسي لملفات التطبيق للعمل بشكل أفضل عند إعادة الزيارة.

## النشر على GitHub Pages
1. ارفع الملفات الثلاثة إلى جذر المستودع.
2. افتح Settings ثم Pages.
3. اختر Deploy from a branch، ثم `main` ومجلد `/ (root)`.
4. احفظ وانتظر اكتمال النشر، ثم افتح رابط Pages.

## ملاحظات مهمة
- التطبيق يقبل قائمة M3U الافتراضية من iptv-org أو ملفاً/رابطاً آخر يملكه المستخدم أو لديه إذن باستخدامه.
- لا يحتوي على رابط YallaShoot أو روابط قنوات مدفوعة.
- بعض روابط البث قد تفشل بسبب توقف المصدر أو قيود CORS أو قيود المتصفح أو عدم دعم الترميز.
- HLS يحتاج اتصال إنترنت؛ يستخدم hls.js من CDN عند الحاجة.
- هذه نسخة أولية محسنة وليست إثباتاً أن كل قناة تعمل. اختبر عدة روابط مصرح بها على الهاتف بعد النشر.
